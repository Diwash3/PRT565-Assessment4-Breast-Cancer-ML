# Breast Cancer Diagnosis Prediction – PRT565 Assessment 4

**Group:** SYD-G1-22

This project compares five machine learning models to classify breast tumours as benign or malignant using the Breast Cancer Wisconsin dataset.

### Technologies Used
- **Language:** Python
- **Platform:** Anaconda, Jupyter Notebook
- **Libraries:** NumPy, Pandas, Matplotlib, Scikit-learn
- **Version Control:** Git and GitHub

### Models Implemented
- Decision Tree
- Random Forest
- Gaussian Naive Bayes
- SVM (RBF)
- Artificial Neural Network (MLP)

### Analysis and Evaluation
Data preprocessing, EDA, feature scaling, PCA, accuracy, precision, recall, F1-score, ROC-AUC, confusion matrices and 12 visualisations.

### Results
**SVM (RBF)** achieved the highest accuracy of **98.25%**, outperforming the other four models on the test dataset.

### Project Files
- `PRT565_Assessment4.ipynb` – Complete implementation
- `data/` – Dataset
- `figures/` – Visualisations
- `outputs/` – Model results
